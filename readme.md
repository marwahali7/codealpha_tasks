# 🎤 Emotion Recognition from Speech

This project detects human emotions from speech audio using deep learning.

---

## 🎯 Objective
To classify speech emotions such as:
- Happy
- Sad
- Angry
- Fearful
- Neutral

---

## 🧠 Approach
- Audio feature extraction using MFCC
- Model: 1D CNN (Conv1D)
- Dataset: RAVDESS / TESS / EMO-DB

---

## 📊 Features Extracted
- MFCC (Mel-Frequency Cepstral Coefficients)

---

## ⚙️ Technologies Used
- Python
- TensorFlow / Keras
- Librosa
- NumPy

---

## 🚀 How to Run
```bash
pip install tensorflow librosa numpy
python emotion_model.py
